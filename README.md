# ☕ Coffee Shop Sales Dashboard

An interactive Excel dashboard that breaks down a coffee shop’s sales performance across years, months, categories, and cities. This project showcases advanced data visualization and storytelling using Microsoft Excel – ideal for business insights and decision-making.

---

## 🧩 Dashboard Features

### 🔄 Filters (Slicers)
- Year: 2021, 2022, 2023
- Month: Jan to Dec
- City: Austin, Chicago, Los Angeles, New York, Seattle

### 📊 Visual Insights
- **Category Transactions** – Coffee, Cold Drinks, Desserts, etc.
- **Revenue by Year** – Donut chart comparing yearly revenue
- **Transactions by Weekday** – Identify peak days (Fri & Sat shine!)
- **Monthly Revenue Trends** – Spot high-performing months
- **Transactions by Year & Month** – Line chart for seasonality analysis
- **Revenue by City** – Pie chart split by 5 major cities
- **Revenue by Product Category** – Bar graph comparison

## 🚀 How to Use

1. Open the Excel file in Microsoft Excel.
2. Use the filters (left panel) to slice the data by Year, Month, or City.
3. Interact with the charts and graphs to explore hidden insights.
4. Use it as a portfolio piece or foundation for business analytics projects.
